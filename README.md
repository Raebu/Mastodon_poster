# Mastodon Poster — Martin Raeburn Social OS

Mastodon-native execution agent for Martin Raeburn, sharing durable intelligence with the LinkedIn and Bluesky agents through the Social OS Google workbook.

## Capabilities

- Original Mastodon posts and replies
- Favourites and boosts
- Following, when enabled by the account token
- Notification and timeline discovery
- Relationship-aware engagement and deliberate `NO_ACTION`
- Cross-platform duplicate protection and shared knowledge/ideas
- Google Sheets audit/memory layer
- Dry-run by default and granular kill switches

Uses only documented Mastodon APIs. Secrets are supplied through GitHub Actions and are never committed.
